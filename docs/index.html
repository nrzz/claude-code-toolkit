Claude Code, cheaper, safer and easier to share

Nineteen small, open-source tools. Each is a dependency-free Node command or plugin that adds few or no tokens to your sessions, and all nineteen are tested together, installed from GitHub, on Windows, macOS and Linux.

$ npx -y github:nrzz/claude-code-toolkit
View on GitHub

Opens a setup page with the recommended tools already switched on: one click on Install sets them up, and each tool's settings are there when you want them. Prefer Claude Code's plugins? /plugin marketplace add nrzz/claude-code-toolkit. Spendcap is in Anthropic's plugin directory: /plugin install spendcap@anthropic-plugin-directory

Built the same way

So you can add one without wondering what it does to your machine, your settings or your bill.

No dependencies

Node 18 or newer and nothing from npm. There is nothing to audit but the code itself.

Token cost is a feature

A hook speaks to the model only when that is its job, like a recalled line or the reason a command was stopped; the rest talks to you. Skills Claude does not need are user-only. Every README states what each part costs.

Your settings stay yours

A backup before every write, only the keys each tool is there for, invalid JSON left alone, and an uninstall that takes out what it added.

Honest READMEs

Each says what was verified and how, and what was not. Each runs its tests on Windows, macOS and Linux with Node 20, 22 and 24, and on Linux with Node 18.

Tested together

One end-to-end run does what a new user would, on a clean machine, and CI repeats it every week so a Claude Code update that breaks a tool shows up.

  3. The one-command setup run as a user would, in a second home folder: install with options, the setup page started for real and driven through its own API, Done, and everything uninstalled again.
  4. All sixteen plugins installed from this marketplace with claude plugin install, their own hooks run from the installed copies, their token estimate checked, the request Claude Code sends the model checked for their user-only skills, and the HUD's engine tests run inside Claude Code.
