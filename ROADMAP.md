# Roadmap

What could come next. None of it is promised; all of it is open to contributors. Comment on an issue or start a [discussion](https://github.com/nrzz/claude-code-toolkit/discussions) before a large change.

- A tool that measures what each MCP server's tool list costs per session, and which ones a project never uses.
- Screenshots or short recordings for every tool's README (a good first contribution: no code needed).
- A `doctor` that lists which toolkit tools are installed, in which version, and whether an update is out.
- Pin marketplace entries to release tags, with a check that the tag exists.
